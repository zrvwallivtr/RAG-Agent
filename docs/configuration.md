# Configuration

Settings live in `~/.agent/config.toml`. If the file is missing, the default is copied
from the code base.

## `[models]`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `ollama_host` | `str` | `http://localhost:11434` | URL for the Ollama docker service from `~/.agent/docker-compose.yaml`, default URL is `http://localhost:11434`. |
| `model` | `str` | `ministral-3:3b` | Language model used for conversation. |
| `embedding` | `str` | `nomic-embed-text` | Embedding model used for all features that requires embeddings (attachments, documents, query knowledge base). |


## Optional Configs

### `[models]`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `fallback_tokenizer` | `str` | `gpt2` | Hugging Face tokenizer for `model` model (must be the exact repo name). |
| `token_reserve` | `int` | `1000` | Token reserve for agent's response. |

If the agent does not know the model's token limit (either form built in or specified in the configs), the token counter and auto compression feature are disabled.

### `[rag]`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `enable_docling` | `bool` | `True` | Use docling by default for parsing files. |
| `retrieve_entry_limit` | `int` | `3` | Set limit for number of entires (chunks) retrieved in one call. |
| `min_similarity_score` | `float` | `0.65` | Set the minimum similarity score required for retrieved entries before sending to the model. |

## `[expert]`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `exploration_factor` | `int` | `100` | Set `ef_search` in `pgvector`, tuning for the query execution for the HNSW index type. |
| `per_expert_retrieval_limit` | `int` | `3` | Set limit for the number of entries retrieved from a single expert call. |
| `docling_chunk_tokens` | `int` | `300` | Set a ceiling to limit the chunk size split by Docling. |
| `minimum_similar_score` | `float` | `0.65` | Set minimum similarity score required for expert document chunks before sending to the model. |
| `reply_reserve_tokens` | `int` | `10000` | Set reservation for the document description generated by the model, for calculating the character count the model can read before context overflow in the document to generate a description. |
| `doc_fallback_chars` | `int` | `12000` | Set the character count estimation the model will generate for the document description, this will only take effect if the tokenizer is not set. |

## `[security]`

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `enable_path_safety` | `str` | `true` | When enabled, agent can only read contents uploaded to `~/.agent/uploads/`. |
